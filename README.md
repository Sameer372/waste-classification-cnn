# Waste Classification Using CNN

This project implements a Convolutional Neural Network (CNN) model for automatic waste image classification.

## Dataset
Dataset: Mendeley Waste Classification Dataset

The dataset contains two categories:
- Organic Waste
- Recyclable Waste

## Model
A basic CNN model was developed using TensorFlow and Keras.

Techniques used:
- Image preprocessing
- Data augmentation
- Dropout regularization
- CNN-based classification

## Result
- Validation Accuracy: 87.35%
- Best Validation Loss: 0.3063
- Epochs Trained: 10

## Conclusion
The model successfully classifies waste images into Organic and Recyclable categories and demonstrates the application of deep learning in automated waste management systems.
